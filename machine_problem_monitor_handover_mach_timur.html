Install Aplikasi di Handphone

Pasang ikon aplikasi di Home Screen HP Anda

Instalasi Otomatis Tersedia

Android (Google Chrome)

  1. Buka link aplikasi ini di browser Chrome.
  2. Ketuk ikon menu ⋮ (tiga titik) di pojok kanan atas.
  3. Pilih Add to Home screen atau Install app.
  4. Konfirmasi Install / Add agar muncul di layar utama HP.

iPhone / iPad (Safari)

  1. Buka link aplikasi ini menggunakan browser Safari.
  2. Ketuk ikon Share (kotak dengan panah ke atas) di bagian bawah.
  3. Geser ke bawah dan pilih Add to Home Screen.
  4. Ketuk Add di pojok kanan atas.
